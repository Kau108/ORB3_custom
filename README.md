# ORB3_custom Workspace

This repository contains a customized environment and wrapper scripts for working with **ORB_SLAM3**. It includes utilities for processing standard ROS bags into formats suitable for ORB_SLAM3, building maps, and processing/plotting the resulting trajectories.

## Directory Structure

### Root Directory (Wrapper & Setup)
The root directory mainly consists of utility scripts for data processing and environment setup:

* **`bag_processing.py` / `rosbag2dataset.py`**: Python scripts used to extract and process data from ROS bags into datasets compatible with ORB-SLAM3 (extracting images, IMU data, and timestamps).
* **`build_map.py`**: Automates the execution of ORB-SLAM3 to build a map from a processed dataset.
* **`process_tracjectory.py`**: A utility script for post-processing the output trajectory files generated by the SLAM system.
* **`run_env.sh`**: A shell script likely used to set up environment variables or launch the Docker environment.
* **`Dockerfile`**: A Docker container definition to ensure a consistent build and execution environment for ORB-SLAM3 and its dependencies.

### `ORB_SLAM3/` (Core SLAM System)
This subdirectory contains the core ORB-SLAM3 C++ library and executables.

* **Build Scripts**:
  * `build.sh`: Script to compile the core ORB-SLAM3 library and examples.
* **Source Code (`src/` & `include/`)**: Contains the core logic of the SLAM system including components like `Tracking`, `LocalMapping`, `LoopClosing`, `MapDrawer`, `Optimizer`, etc.
* **Libraries & Build (`lib/` & `build/`)**: Compiled static/shared libraries and CMake build artifacts.
* **`Examples/`**: Contains example executables to run ORB-SLAM3 with different sensor configurations (Monocular, Stereo, RGB-D, Inertial).
* **Dependencies (`Thirdparty/`)**:
  * `DBoW2`: Bag-of-words library for place recognition and loop closing.
  * `g2o`: Graph optimization library used for bundle adjustment.
  * `Sophus`: Library for Lie groups (used for camera poses and transformations).
* **`Vocabulary/`**: Contains `ORBvoc.txt`, the visual vocabulary required by ORB-SLAM3 for feature matching and relocalization.
* **Outputs**: Files like `CameraTrajectory.txt` and `KeyFrameTrajectory.txt` which reflect the estimated path of the camera.
* **`Plot_Trajectory.py`**: Included near the root of the ORB_SLAM3 directory, used for visualizing the generated camera trajectories.

## Getting Started
1. Enter the Docker environment by running `./run_env.sh` from the root directory.
2. Once inside the Docker container, run `./build.sh` inside the `ORB_SLAM3` directory to compile the core system and third-party dependencies.
3. Use the Python scripts in the root directory to process your `.bag` files into datasets.
4. Run the SLAM system to generate Map and Trajectory files.
   *Example: Run the following from the `ORB_SLAM3` directory (still inside the Docker container):*
   ```bash
   ./Examples/RGB-D/rgbd_tum Vocabulary/ORBvoc.txt Examples/RGB-D/Zed2/Zed2.yaml Examples/RGB-D/Zed2 Examples/RGB-D/Zed2/associations.txt
   ```
5. Process and visualize the results using the trajectory python scripts.
